# TTA 표준 조항 색인

설계 문서가 인용하는 조항을 표준 원문 변환본의 해당 위치로 직접 연결한다. 조항과 안심코드 구현의 **매핑**은 [TDD §1 Context](../tdd.md#1-context)에 있고, 이 문서는 **위치 색인**만 담당한다.

> `§`만 적힌 인용은 문서 자신의 절을 가리키는 경우와 표준 조항을 가리키는 경우가 섞여 있다. 표준 조항은 `0259 §11.3`처럼 표준 번호를 앞에 붙인 표기만 이 색인의 대상이다.
