# 소프트웨어 개발보안 가이드 (2021)

행정안전부와 한국인터넷진흥원이 발간한 전자정부 SW 개발·운영자용 개발보안 가이드다. 「행정기관 및 공공기관 정보시스템 구축·운영 지침」(행정안전부고시 제2021-3호)이 요구하는 **설계단계 보안설계 기준 20개 항목**과 **구현단계 보안약점 제거 기준 49개 항목**의 원문 기준이며, 항목별 취약점 개요·설계 시 고려사항·JAVA/C/C# 코드예제를 담고 있다.

원본이 376쪽에 이르므로 장 단위로 파일을 나누어 보관한다. 요약본이 아니라 표지·본문·부록 전체를 옮긴 것이다.

## 문서 변환에 관하여

- 원본 PDF는 저장소에 포함하지 않는다. 각 문서 상단 인용 블록에 원본 파일명을 적어 두었다.
- 페이지 머리글·바닥글, 측면 장 인덱스, 목차의 페이지 번호는 제거했고, 그 밖의 원문 내용은 그대로 옮겼다.
- 원문의 그림은 `**[그림 N-N] 캡션**` 형태로 표기하고 구성요소와 흐름을 텍스트로 풀어 썼다. 캡션이 없는 삽화도 `**[그림] …**`로 표기했고, 뉴스 기사 캡처처럼 본문 이해에 필요하지 않은 이미지는 `(화면 캡처)`로만 표시했다.
- 표는 마크다운 표로 옮겼다. 셀 병합이 있는 표는 구조를 근사해 표현했고, 셀 안의 줄바꿈은 `<br>`로 표기했다.
- 코드예제는 언어별 코드 블록으로 옮겼다. 원문의 들여쓰기와 주석은 그대로 두었고, 원문에 있는 오탈자도 고치지 않았다.
- 각주는 본문 해당 위치에 `> <sup>N</sup> …` 형태의 인용 블록으로 두었다.
- 원문의 하이픈은 U+2010(‐) 등 다양한 문자를 쓰지만, 표기 일관성을 위해 표·그림 번호와 표준 식별자(SR1-1 등)는 ASCII 하이픈으로 통일했다.
